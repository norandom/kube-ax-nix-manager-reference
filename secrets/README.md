# secrets/

Everything in this directory except this README is gitignored, and a pre-commit hook rejects it too.

| File | Created by | Purpose |
|---|---|---|
| `k3s-token` | generated by `just k3s` | Shared k3s cluster join token |
| `ghcr-token` | operator | Classic PAT, `read:packages`: node pulls from ghcr.io |
| `ghcr-push-token` | operator | Classic PAT, `write:packages`: `ko` pushes for `just platform` |
| `openobserve-auth` | operator | base64 `user:token`, **ingestion only**: collectors send telemetry |
| `openobserve-admin` | operator | `user:password` with alert rights: `scripts/openobserve-alerts.py` |
| `rustfs-credentials` | operator | `access-key=…`, `secret-key=…`: Substrate snapshots (S3) |
| `gitea-runner-token` | operator | Gitea Actions runner registration |
| `discord-webhook` | operator | Discord webhook URL for OpenObserve alerts (anyone with it can post) |
| `discord-user-id` | operator | Discord user mentioned in alerts |

All files should be mode `0600`.
