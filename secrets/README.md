# secrets/

Everything in this directory except this README is gitignored, and a pre-commit hook rejects it too.

| File | Created by | Purpose |
|---|---|---|
| `k3s-token` | generated by `just k3s` | Shared k3s cluster join token |
| `ghcr-token` | operator | Classic PAT, `read:packages`: node pulls from ghcr.io |
| `ghcr-push-token` | operator | Classic PAT, `write:packages`: `ko` pushes for `just platform` |

All files should be mode `0600`.
